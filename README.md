## Структура проекта



app/src/main/java/com/example/mynotes/
├── MainActivity.kt # Главный экран
├── NoteDetailActivity.kt # Детали + удаление + AlertDialog
├── AddNoteActivity.kt # Добавление + timestamp + цвет
├── data/
│ ├── AppDatabase.kt # Room БД
│ ├── Note.kt # Модель с timestamp
│ ├── NoteDao.kt
│ └── NoteRepository.kt
└── adapters/
└── NoteAdapter.kt # Карточки с датой и цветом




## Как собрать проект

1. Открыть в Android Studio
2. Синхронизировать Gradle
3. Запустить на эмуляторе или устройстве
